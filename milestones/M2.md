# M2: 规则 7.x 补齐（函数表达式块 / 选择表达式 / 循环表达式）✅

目标：补齐规则 7.0-7.4 的语法、语义、IR 支持，使 `{ stmts; expr }`、`if {} else {}`、`loop { break expr; }` 能作为表达式求值。**已达成**。

## 设计决策（2026-07-02，方案 A）
- **统一表达式化**：if/loop/block 升级为表达式节点（IfExpr/LoopExpr/Block+TailExpr），作语句时值丢弃，作块值/右值时求值
- **node_ir_temp + node_block_type**：表达式求值结果（temp）与块值类型分别用两个 map 传递
- **block_tail_as_return + amFuncBody**：函数体直接块的末尾 TailExpr 作隐式 return（7.2）；嵌套块（then/else/loop body）不复位传播
- **hasValue/hasBreakValue 预检查**：IfExpr 仅当 then/else 有 TailExpr 才分配结果 temp；LoopExpr 仅当有带值 break 才分配 loop_result——保证现有 if/loop 语句的 IR 与旧 IfStmt/LoopStmt **逐行一致**（golden 零回归）

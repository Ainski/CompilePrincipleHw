# M2: 规则 7.x 补齐（函数表达式块 / 选择表达式 / 循环表达式）

目标：补齐规则 7.0-7.4 的语法、语义、IR 支持，使 `{ stmts; expr }`、`if {} else {}`、`loop { break expr; }` 能作为**表达式求值**。这是当前唯一完全缺失的拓展规则块（⭐⭐⭐ × 5）。

前置：M1 完成（在合并 visitor 上扩展）。

## 任务清单
- [ ] 2.1 parser：`parseBlockExpr` —— 函数表达式块 `{ <语句串> <表达式> }`，末尾表达式（无分号）作为块的值；与语句块（无末尾表达式）区分
- [ ] 2.2 parser：`parseIfExpr` —— 选择表达式 `if <expr> <block> else <block>` 作为表达式
- [ ] 2.3 parser：`parseLoopExpr` —— 循环表达式 `loop { break <expr>; }` 作为表达式
- [ ] 2.4 合并 visitor（语义）：块表达式取末尾表达式类型；选择表达式两分支类型须一致；循环表达式取 break 表达式类型，多个 break 须类型一致
- [ ] 2.5 合并 visitor（IR）：块表达式求值、选择表达式短路、循环表达式 break 值回填的四元式生成
- [ ] 2.6 测试：规则 7.0-7.4 正向用例（块/选择/循环表达式正确求值）+ 负向用例（break 不在循环、break 类型不一致、两分支类型不一致）
- [ ] 2.7 回归：22 项 `semantic_tests.sh` 不回归

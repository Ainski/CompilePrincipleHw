# M3: 目标代码生成（x86-64 AT&T 汇编）

目标：从四元式 IR 翻译到**可汇编执行**的 x86-64 AT&T 汇编（`.s`），用 gcc/gas 汇编链接为可执行程序，运行结果正确。这是作业 3 的核心增量，决定编程项能否拿 A 档（slide 31）。

前置：M2 完成（在完整 IR 上做后端）。

## 任务清单
- [ ] 3.1 `CodeGenerator` 模块骨架：消费 `vector<Quadruple>`，输出 `.s` 文本；接入 `main.cpp`（新增 `--asm-output` 参数）与 CMakeLists
- [ ] 3.2 栈帧管理：函数 prologue（`push %rbp` / `mov %rsp,%rbp` / `sub $N,%rsp`）/ epilogue；局部变量与临时变量的**栈槽分配表**（先用栈式映射，不做事寄存器分配）
- [ ] 3.3 算术/赋值/比较翻译：`ASSIGN/ADD/SUB/MUL/DIV/NEG` → `mov/add/sub/imul/idiv/neg`；`EQ/NE/LT/LE/GT/GE` → `cmp` + `setCC` + `movzbl`
- [ ] 3.4 控制流翻译：`LABEL` → `.Ln:`；`JUMP` → `jmp`；`JZ/JNZ` → `cmp` + `je/jne`
- [ ] 3.5 函数调用约定（System V AMD64）：`PARAM` → 参数入寄存器（rdi/rsi/rdx/rcx/r8/r9）或栈；`CALL` → `call`；`RETURN` → 返回值入 `rax` + `ret`
- [ ] 3.6 内存结构：数组/元组的布局与索引（`INDEX_LOAD/INDEX_STORE` → 地址算术 `mov`）；引用/解引用（`REF/DEREF` → `lea` / 间接 `mov`）
- [ ] 3.7 汇编输出与构建：`--asm-output foo.s`，手动 `gcc foo.s -o foo` 验证可汇编链接
- [ ] 3.8 端到端测试：源码 → IR → asm → 可执行，运行核对结果（如 `fibonacci(10)` 返回 55）
